# 4학년 기부 유닛 아카이브

서원초 4학년 학생들이 해피빈 기부 캠페인 데이터를 조사하고, 판단 기준을 설계·토론하여 실제 기부로 실천한 과정을 6학년 학생들에게 공유하는 GitHub Pages용 웹사이트입니다.

## 바로 배포하기

1. 새 GitHub 저장소를 만듭니다.
2. 이 폴더의 `index.html`과 `images` 폴더를 저장소 최상단에 올립니다.
3. 저장소의 **Settings → Pages**에서 `Deploy from a branch`를 선택합니다.
4. Branch를 `main`, 폴더를 `/ (root)`로 설정하고 저장합니다.

## 이미지

`images` 폴더의 이미지는 연구보고서에 수록된 자료에서 추출하여 웹용으로 용량을 줄였습니다. 공개 배포 전 학생 얼굴·이름 등 개인정보 노출 여부를 최종 확인하세요.

## 주요 수정 위치

- 제목과 설명: `index.html`의 `<header class="hero">`
- 핵심 수치: `<section class="stats">`
- D-A-T-A 과정: `<section class="section" id="journey">`
